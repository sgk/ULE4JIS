# ULE4JIS - US Keyboard Layout Emulator for JIS

## 概要

ULE4JIS（US Keyboard Layout Emulator for Japanese Input System）は、日本語キーボードドライバ上でUSキーボードレイアウトをエミュレートするWindows用ツールです。

**フォーク元:** [dezz/ULE4JIS](https://github.com/dezz/ULE4JIS)

## このフォークでの変更点

### 機能追加
* **Caps LockでIMEをオンオフする機能** - 以下の3つのモードから選択可能：
  * **Alt + ｀ (従来方式)**: 半角/全角キー（スキャンコード0x29）を送信してIMEを切り替え（日本語キーボード向け）
  * **IMEを直接オンオフ (新方式)**: IME APIを直接呼び出してIMEを切り替え（USキーボード向け）
  * **無効**: Caps Lockキーを通常通り使用
* 起動時にCaps Lock LEDが点灯している場合、自動的にオフにする（Caps Lock機能が有効な場合のみ）
* 起動時にウィンドウではなくスプラッシュスクリーンを表示
* タスクトレイのメニューを整理
* レイアウト変換機能、IMEオンオフ機能を個別に無効化
* 上記設定は次回起動時に再現される

### ビルド環境の更新
- Platform Toolset v145 (Visual Studio 2026) へアップグレード

### コード品質の改善
- **文字エンコーディング**
  - `KeyHooker.cpp` を UTF-8（BOM付き）に変換
  - リソースファイル（`Ule4Jis.rc`）を UTF-8 に変換
  - コードページを932（Shift-JIS）から65001（UTF-8）に変更

- **UI改善**
  - Copyright表記を `(C)` から `©` 記号に変更
  - タスクトレイアイコンの左クリック・右クリック両方でメニューを表示
  - ダブルクリック機能を削除（シンプル化）
  - メインウィンドウ表示機能を削除（タスクトレイのみで動作）

- **バグ修正**
  - トレイメニューから終了した時に設定が保存されない問題を修正
  - `OnClose()` ハンドラーを追加し、終了前に確実に設定を保存

### 警告の修正
- **C4819:** ファイルエンコーディングの警告 → UTF-8変換で解決
- **C4302:** 型キャスト警告 → スコープ付きプラグマで抑制（Win32 APIの標準パターン）

## 使い方

1. `Ule4Jis.exe` を実行
2. タスクトレイにアイコンが表示されます
3. アイコンを左クリックまたは右クリックでメニューを表示
4. 設定を変更：
   - **有効**: キーエミュレーション機能の有効/無効
   - **日本語キーボードでUS配列**: USキー配列エミュレーションの有効/無効
   - **Caps Lockの動作**: 以下から選択
     - **Alt + ｀**: 日本語キーボード向け（デフォルト）
     - **IMEを直接オンオフ**: USキーボード向け - IMEを直接制御するため、より確実に動作
     - **無効**: Caps Lockキーを通常通り使用
5. 終了時に設定は自動的に保存されます

### 推奨設定

#### 日本語キーボードの場合
- **日本語キーボードでUS配列**: ✓ 有効
- **Caps Lockの動作**: Alt + ｀

#### USキーボードの場合
- **日本語キーボードでUS配列**: 無効
- **Caps Lockの動作**: IMEを直接オンオフ
